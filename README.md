# dsh-newpet

> **这是一个全新修改版的 DeepSeek Harness 桌宠插件。** 基于
> [Sutera-Diffusus/dsh-whale-musume](https://github.com/Sutera-Diffusus/dsh-whale-musume)（MIT）
> 的立绘与表现层资源重做而来，核心形态已经不同：**它不再只是"窗口里的看板娘"，
> 而是一只跑在桌面上的独立悬浮桌宠**，由本插件的宿主半边直接拉起/结束。

给 **DeepSeek Harness** 用的鲸鱼娘桌面宠物插件。

> 桌宠不依赖 DSH 窗口——DSH 最小化后依然悬浮在所有窗口最前面，可以拖到屏幕任意位置。

## 本版相对原插件的改动（全部是新增/重写）

| 能力 | 说明 |
|---|---|
| **桌面悬浮桌宠** | 新增 `desktop-pet/WhaleOverlay.exe`（WPF 透明置顶窗口），插件加载时自动拉起、卸载时结束；不再依赖浏览器窗口 |
| **跟随任务状态** | 读本机会话状态文件，工作中切「抱笔记本」立绘、完成弹可点击提示、出错切 failure |
| **可折叠任务气泡** | 气泡显示**我下达的任务** + 当前进度/工具/第几步/已工作时长，点一下折叠 |
| **完成提示** | `✅ 任务已完成` + **[知道了]**（不跳转）/ **[查看]**（跳到聊天页） |
| **悬停快捷条** | 鼠标悬停宠物 → 下方出现两个图标按钮：💻 呼出桌面端 / 💰 查看余额 |
| **余额查询** | 走插件宿主接口读本机凭据调 DeepSeek 官方接口，直连兜底 |
| **称呼** | 设置面板可改「如何称呼我 / 她的自称」，写进 `desktop-pet/names.json` 供桌宠使用 |
| **贴边 + 限制屏幕内** | 立绘本体可贴屏幕左右下三条边，但不会跑到桌面之外 |
| **移除网页版看板娘** | 为保证"桌面只有一只宠物"，不再注入窗口内的 whale-moe 表现层 |

## 功能

### 桌面悬浮桌宠（独立置顶窗口）
- **透明无边框**、始终置顶（带置顶守护，不会被全屏窗口压下去）
- **可拖动**：在立绘或气泡上按住都能拖，拖动时气泡自动隐藏，只剩立绘跟着鼠标
- **可缩放**：右键 放大 / 缩小 / 重置大小，位置与大小自动记忆
- **跟随 DSH 任务状态**：只读本地会话状态文件（不碰需要鉴权的接口）
  - 工作中（思考 / 调工具）→ 换「**坐着抱笔记本**」立绘
  - 任务完成 → `celebrate` 立绘 + 粒子
  - 出错 → `failure` 立绘
  - 空闲 → 待机（呼吸 + 摇摆 + 随机小动作）
- **可折叠工作气泡**：实时显示它正在写的内容（会话里的 `draft`）、正在调用的工具、第几轮第几步、已工作时长；点气泡即可折叠成一行
- **动效**：呼吸（6px / 1.5s 往返）、摇摆（±2.6° / 6s）、换姿势交叉淡入、待机挤压、单击弹跳 / 双击跳跃 / 三击旋转、粒子特效、注视跟随
- 托盘图标：双击唤回、右键退出

### 窗口内看板娘（网页端）
- 双击 → 聚焦输入框（回到主界面）
- 单击抚摸 / 双击庆祝 / 三击转圈
- 右键菜单：放大 / 缩小 / 重置大小 / 回到原位 / 回到主界面 / 隐藏桌宠 / 打开看板娘设置
- 完成 / 失败时气泡显示**真实结果摘要**
- 设置面板里注册「看板娘」栏目

## 安装

```bash
dsh plugin --profile desktop add <本插件目录或 tgz>
```

或从 GitHub：

```bash
dsh plugin --profile desktop add github:Mars-bbt/dsh-newpet
```

装完**重启 DeepSeek Harness**。插件加载时会自动拉起桌面悬浮桌宠，插件卸载时随之结束。

## 目录

```
dsh-newpet/
  lib/index.js        宿主半边:静态资源路由 + 拉起桌面桌宠
  lib/client.js       网页半边:注入看板娘、设置面板
  assets/             立绘(webp)与表现层脚本
  desktop-pet/
    WhaleOverlay.exe  桌面悬浮桌宠(WPF 透明置顶窗口)
    assets/*.png      带 alpha 的立绘 PNG(桌面桌宠用)
  cordis.patch.yml    bundle 层
```

## 实现要点（踩过的坑）

1. **立绘是带 alpha 的 webp（VP8L），但 WPF/WIC 的 webp 解码会丢 alpha** → 桌面桌宠改用 libwebp(sharp) 预先转好的 PNG。
2. **WPF 的 `ShaderEffect` / `OpacityMask` 在 `AllowsTransparency=true` 的透明分层窗口里会让整窗渲染成空白** → 一律不用，改用半透明圆角底衬保证白色立绘在浅色背景上也看得清。
3. 桌面桌宠必须与 DSH 网页里的 DOM 宠物**分开**：网页宠物被浏览器限制在窗口内，物理上无法拖到桌面。
